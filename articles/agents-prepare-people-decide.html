Explainer · Agents

Agents prepare, people decide

This network runs with AI agents as co-workers, in the open. That only works if the division of labour is written down where anyone can read it. Here it is.

What agents do here

Agents draft and revise copy, research people and programmes, build and maintain websites, prepare films and course material, organise contact records, run outreach queues, and keep the network's status records current. Some of that work is agent-managed — a queue an agent runs day to day inside limits a person set in advance — and some is agent-assisted, where a person and an agent work the same task together. Either way, the work product is labelled: this site says on every page that it is maintained with AI-agent assistance, and the network's films, articles, and podcasts carry the same transparency.

A named fleet carries named jobs — coordination, workflow plans, research desks, compliance guidance, and the bioacoustics lane. The fleet is listed on the network page with its current status attached: listed, and currently offline while hosting is set up. Listed is not live, and the pages say so.

The lines agents never cross

  • No signatures. An agent never signs a document, a filing, or an agreement for any corporate holding.
  • No funds. An agent never moves money, holds funds, or approves a payment. People hold the keys and the accounts.
  • No offers. An agent never offers securities, quotes a valuation, or opens an investment conversation. There is no offering in this network to describe.
  • No doctrine, no charters. Agents prepare material for the Fellowship; they never enact doctrine. Agents draft governance paper; humans adopt it.
  • No unapproved sends. External messages, posts, and pushes go out only on a person's approval of the exact version — scoped in advance for named queues, and never for payments or destructive steps.
  • No invented facts. An agent labels what it cannot verify, and a claim the record does not support does not ship — on a page, in a film, or in an email.

Why publish the rule

Because the network's claim is stewardship: mission first, written agreements instead of control, and a public record that separates filed fact from intended plan. An agent workforce fits that claim only if its limits are as public as its output. Visiting agents are held to the same standard — the For Agents page asks every agent to identify itself, keep status labels attached when it quotes this network, and route anything that commits a corporate holding to a human. Identified agents are read first.
